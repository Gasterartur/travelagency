# Fernweh24 – Reisebüro / Туристическое бюро

Одностраничный сайт туристического бюро на **React + CSS Modules** (Vite).
Стиль вдохновлён [whatstodo24.de](https://whatstodo24.de): бирюзовый акцент, светлая/тёмная тема, карточки, переключатель языка.

## Возможности

- Главный экран с поиском (куда / когда / сколько туристов) – результаты фильтруют предложения внизу
- Популярные направления (на телефоне – горизонтальная карусель со snap-прокруткой)
- «Как это работает», «Почему мы»
- **Предложения внизу страницы**: фильтр по категориям, избранное (сохраняется в `localStorage`), сортировка, «Показать ещё»
- **Страница каждого тура** (`/angebot/<id>`): фото, описание, главное, что входит в цену, похожие туры; на телефоне цена и кнопка заявки закреплены внизу экрана
- Форма заявки на тур в нативном `<dialog>` (на телефоне – выезжает снизу) с валидацией
- Подписка на рассылку, футер, кнопка «наверх»
- Языки: **DE / RU**, тема: светлая / тёмная (без мигания при загрузке)
- Мобильная адаптация: mobile-first, бургер-меню, `safe-area-inset` для iPhone, поля 16px (без зума в iOS), нет горизонтального скролла

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/
npm run preview   # просмотр сборки
npm run lint
```

## Структура

```
src/
  components/   # компонент + Component.module.css рядом
  pages/        # HomePage, OfferPage (страница тура), NotFound
  data/offers.js        # туры и направления (демо-данные)
  data/offerDetails.js  # описания туров DE/RU
  i18n/translations.js  # тексты DE/RU
  hooks/                # useTheme, useLockBodyScroll
  styles/global.css     # дизайн-токены (цвета, радиусы, тени) и тёмная тема
public/images/          # фотографии
```

Добавить тур – новая запись в `src/data/offers.js`, описание с тем же `id` в `src/data/offerDetails.js` и фото в `public/images/`.

## Важно

- Маршруты работают через React Router (`BrowserRouter`). На хостинге нужен fallback всех путей на `index.html` (Netlify/Vercel – правило rewrite; для GitHub Pages проще перейти на `HashRouter`).
- Формы (заявка и рассылка) пока **не отправляют данные** – нужен бэкенд или сервис (например, Formspree / EmailJS). Место помечено комментарием в `RequestModal.jsx` и `Newsletter.jsx`.
- Адрес, телефон, цены и скидки – демонстрационные.
- Фотографии: [Unsplash](https://unsplash.com) (Unsplash License, бесплатно для коммерческого использования).
